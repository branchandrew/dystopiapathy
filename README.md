# Dystopiapathy

Data and tools from the Dystopiapathy YouTube channel.

- **[TTRPG Matcher](https://dystopiapathy.com/calculator/)** (the site's home page, dystopiapathy.com): find the right TTRPG
  for your table from 148 scored games.
- **[TTRPG crunch ratings](https://dystopiapathy.com/crunch/)**: crunch scores for 101 tabletop RPGs
  (total, minimum, GM and player complexity), with the full data set as CSV in [`crunch/data/`](crunch/data/).
